## 1. 一句话定位

> **一个面向全球的、移动优先的 PWA 学习平台:把「作业 · 训练 · 测评 · 考试」做成一套,
> 覆盖全学科,以 AI 辅助评测为核心,自适应手机/平板/PC,可商业化运营。**

## 1.5 v1 现状定位(已上线,口径以此为准)

> 本文档其余部分是**北极星 / v2 愿景**;这一节是**当前 v1 实际在做的事**。对外描述以本节为准。

**一句话**:**你好！作业**是一个**手机优先的英语口语训练与测评平台**,面向**大、中、小学各学段学生,
以及希望提升英语表达能力的成人英语学习者**——覆盖**朗读 · 背诵 · 模仿 · 口语 · 演讲**五类练法,
贯穿**练习 · 作业 · 测评 · 考试**四种形态。

**核心机制(最锋利的差异)**:老师发布**多环节任务、逐环节设定评分标准**;学生**录音/录视频**逐环节
提交;**AI 照着老师为该环节设定的标准分环节自动评阅**(先感知发音/流利度,再对标判分并给逐句反馈),
老师只需**复核**。—— 即「AI 照老师的标准评,不是照通用模板评」,老师从"逐个听"变成"抽查复核"。

**两条闭环**:
- **老师侧**:发布多环节任务(逐环节定标准)→ 学生提交 → AI 按标准分环节评 + 逐句反馈 → 老师复核 →
  班级学情 → 一键导出成绩。
- **学生侧**:录音/录视频提交 → 拿到按标准的分环节评分与逐句反馈 → 看个人分析/薄弱点/趋势 →
  针对性训练 → 再提交。

**受众 ↔ 形态**:
- **学校 / 培训机构(有老师)**:作业 · 测评 · 考试为主,同一套评阅闭环。
- **成人自学者(无老师)**:以**练习**态自跑「提交 → AI 按标准评 → 看分析 → 再练」闭环。

**四态在 v1 的成熟度(诚实标注)**:**作业**态成熟;**练习**(自由练习)可用;**测评**以学情 / AI 批改
校准 / 薄弱点画像呈现;**考试**已有"正式测试 · 强分层防作弊"雏形。v2·阶段 B 再把训练/测评/考试
**深化**(掌握度图谱、自适应、计时随机化),阶段 C 把**学科**从英语泛化到全科(见 §6)。

## 2. 从 → 到(这次重新定位)

| 维度 | 起点(v1) | 目标 |
|---|---|---|
| 学科 | 英语(口语:朗读/背诵/模仿/口语/演讲) | **全学科** |
| 形态 | 练习/作业/测评/考试(四态雏形) | **四态深化**(掌握度图谱/自适应/计时随机化考) |
| 端 | 手机录制网页 | **PWA 原生优先**、可安装/离线/推送、**自适应 Pad/PC** |

| 商业 | 无 | **可能订阅/授权商业化** |

## 3. 四种形态(核心概念)

| 形态 | 语义 | 特征 |
|---|---|---|
| **作业 Homework** | 布置 + 计分 + 截止 | 已有;泛化到全科 |
| **训练 Training** | 自定步调、可重复、形成性 | 重掌握度;喂知识图谱;不一定计分 |
| **测评 Assessment** | 诊断/形成性测量、可自适应 | 产出掌握画像,驱动训练推荐 |
| **考试 Exam** | 总结性、计时、安全交付 | 防作弊、随机化、（可选)监考 |

## 4. 目标用户与场景

- **学生**:手机为主完成作业/训练/测评/考试,离线可作答、联网即同步。
- **老师**:布置、AI 初评 + 人工复核、学情/掌握度分析、按学科组织内容。
- **学校/机构(B2B)**:多租户、按校/班授权计费。
- **全球个人(B2C,潜在)**:多语言自助使用。

## 5. 架构与数据模型含义(这部分直接喂 v2)

> 这正是「先写文档」的价值:每条都落到 v2 的 schema / 计算 / PWA / 计费。

1. **数据模型泛化(最大的一处)**
   现模型是「背诵」形状:`Assignment → Phase → Sentence`、`Submission`(含录像/逐句)。需泛化为:
   - `Activity`(替代 Assignment)带 **mode**:homework/training/assessment/exam;
   - `Section/Part`(替代 Phase);
   - **`Item`(替代 Sentence)带 item-type**:背诵/朗读(语音)、选择、填空、简答、作文、数学、文件上传、口语、编程……
   - `Attempt/Response`(替代 Submission)按 item 存作答。
   迁移时把「背诵」做成 item-type 之一,而非唯一形状。

2. **评测引擎可插拔**
   现有「感知→评分」AI 流水线是**一种** grader。按 item-type 接不同 grader:选择题自动判、作文 AI 批、数学判等、语音感知(现有)。`lib/domain/grading` 泛化为「按 item-type 路由 grader」。

3. **知识库 + 知识图谱**(已在 v2 计划内)
   课程/题库/语法 → **pgvector** RAG 知识库;概念→例句→掌握度→先修 → **图谱**(CTE 起步)。测评/训练靠它做自适应与推荐。Postgres + pgvector 是 v2 地基。

4. **PWA 原生优先**
   service worker **离线作答**、**Web Push** 通知、background sync(离线提交→联网同步)、可安装。manifest 已有;离线/推送/同步要补。多端自适应已有响应式基础,需为 Pad/PC 强化布局。

5. **全球化 / 多区域**
   多语言已 zh/en/es(可扩);需内容本地化、日期/格式(时区已统一)、**多区域低延迟**(v2 计算选型时定区域;媒体走 R2/CDN)。

6. **商业化 / 计费**(新域)
   套餐分层(free/pro/校/区)、订阅计费(Stripe 类)、entitlement 校验、用量计量、多租户按校计费。是 v2 后期新增的 `lib/domain/billing` 类模块。

7. **考试安全**
   计时交付、题目随机化、**防作弊**(扩展现有前端违规记录)、安全提交;监考(摄像头能力已有)按需。

## 6. 分期(北极星 vs 近期)

> **近期范围明确收窄:仍从英语这一科起步,先用英语把「四态」走通,再泛化到全科。**

- **v2 · 阶段 A(地基,先做)**:照 `docs/V2-MIGRATION.md` 把现功能**原样**迁到
  Postgres + pgvector + Fly/Cloud Run;**不加新产品范围**,先把平台地基换稳、测试全绿、上线。
- **v2 · 阶段 B(英语·补齐四态 —— 近期重点)**:在已有的英语背诵**作业**之上,补齐
  **训练/练习 + 测评 + 期末考试**:
  - 数据模型**只泛化到「mode(作业/训练/测评/考试)」一层**,item-type 先保持「背诵/语音」一种;
  - **训练**:自定步调、可重复、不计分(或形成性);**测评**:诊断/掌握度画像;
    **期末考试**:计时、题目随机化、防作弊(扩展现有前端违规记录)、安全交付;
  - 可起**英语内容的知识库/图谱**(pgvector + CTE)驱动测评/训练的自适应;
  - **目标:在一个学科上把四态跑通、验证产品价值,再谈全科。**
- **v2 · 阶段 C(泛化全科)**:把模型从「英语背诵」推广到其它学科 + 更多 item-type
  (选择/填空/简答/作文/数学/口语…);评测引擎按 item-type **可插拔**;落地更广的知识库/图谱。
- **v2 · 阶段 D(商业化 + 原生)**:订阅/计费;PWA 离线/推送/同步;全球化打磨与多端强化。
- **北极星**:第 1–5 节的完整愿景 —— **不要求一次做完**,按 A→B→C→D 推进。

## 7. 暂不做 / 边界(避免愿景膨胀成清单)

- 不做完整的 LMS/校务系统(SIS)、不做实时协作白板、不做社交社区 —— 聚焦「练-测-评-考 + AI 评测」。
- B2C 全球自助在 B2B(学校)跑通前不重投入。
- 监考/反作弊先做「够用的前端 + 服务端校验」,不一上来就上重型 proctoring。

## 9. 一句话结论

**v1 是「英语口语训练与测评」(朗读/背诵/模仿/口语/演讲 × 练习/作业/测评/考试,英语域);v2 要成为
「全球、多端、可商业化的全科练测评考平台,以 AI 评测为核心」——泛化的主要是**学科**。**
路径是:**先用 Postgres 地基把现功能稳稳迁过去(阶段 A),再用英语这一科把「四态」补齐——训练/
测评/期末考试(阶段 B),然后泛化到全科(阶段 C),最后叠加商业化与原生 PWA(阶段 D)** ——
**文档先行、单科先行**,是为了让这几步不返工。
