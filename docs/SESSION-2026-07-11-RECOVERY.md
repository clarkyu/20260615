## §2 本轮运维答疑(clark 问的,记下便于复用口径)

- **「免计」(EXEMPT)是什么**:学期总评工作台里,把某生某一类别**整个移出他的总评**,其余类别权重
  重归一(算法 `review.ts` `computeTotal`:`c.exempt` → `continue`,不进 sum 也不进 wsum)。
  与「计0」区别大:课堂30/训练30/期末40 下,某生课堂免计+训练80+期末90 → 总评 (80×30+90×40)/70=**85.7**;
  同一人课堂计0 → **60.0**。用途:该类别对该生本不该有分(中途转入没上雨课堂、正式请假免修)。
- **免计如何还原**:工作台点该格 → **「还原自动分」**(`clearReviewOverride`,删 override 行回自动分,
  幂等可逆,原始数据从未动)。同一按钮也还原「改分」「填60」(本质同一种 override 记录)。
  提醒:已发布过的班还原后要**重新发布**才更新学生端;已导出的班要**重新导出**。
- **生产域名** = `https://www.hihomework.com`(`wrangler.jsonc` APP_URL)。
- **导入直达链接**(offeringId↔班号见 07-10 档 §5):`.../dashboard/teaching/{offeringId}/review/import`。
- **我无法代 clark 点导入**:导入是要老师登录会话的 server action;绕过去的两条路(base64 走 Actions
  输入 / 提交进 git)都会把未成年人 PII 泄进 CI 日志或版本库,违背最小披露原则,不做。
