## 0. 标准口径(改这里,别处复制)

**一句话(标准版)**

> **你好！作业** 是一个**手机优先的英语口语训练与测评平台**,面向**大中小学生与成人英语学习者**——
> 覆盖**朗读 · 背诵 · 模仿 · 口语 · 演讲**五类练法,贯穿**练习 · 作业 · 测评 · 考试**四种形态。老师发布
> **多环节任务、逐环节设定评分标准**,学生录音/录视频提交,**AI 就照着这套标准分环节自动评阅**、老师
> 复核;老师按班级看学情、一键导出成绩,学生拿到个人分析与总结后**针对性训练**。

**一句话(短版 · 主打差异)**

> 老师给每个环节定标准,**AI 就按你的标准分环节评**——把全班的口语作业先评一遍、逐句反馈,老师只复核。

**核心差异(对外主打)**

> **「AI 照老师的标准评,不是照通用模板评」**:评分标准由老师逐环节设定,AI 只把它规模化执行到全班每次
> 提交,老师从"逐个听"变成"抽查复核"。

**环节形态(题型 · 可在一份任务里混搭)**

> 每个环节可独立设为四类之一:**口语**(朗读/背诵/模仿/口语/演讲,AI 语音评)· **写作**(自由文本/默写,
> **AI 按老师设的标准做文本评分 + 逐维反馈**)· **客观**(单选/多选/判断/填空,**提交即自动判分**,不占老师
> 精力)· **投票**(无正确答案,只统计分布)。口语是旗舰差异;写作与客观题让**测评 / 考试**能出真正的**综合卷**。

**受众**

> 大、中、小学各学段学生;希望提升英语表达能力的成人英语学习者。校园班级、英语培训机构、个人自学皆可用。

**两条闭环**

- 老师侧:`发布多环节任务(逐环节定标准) → 学生提交 → AI 按标准分环节评 + 逐句反馈 → 老师复核 → 班级学情 → 一键导出`
- 学生 / 自学侧:`(自由)选题 → 提交对应文稿 → 对着文稿自由练习 → 检测练习成果 → 按结果针对性训练 → 再练`(没有老师的自学者也能独立跑通)

**受众 ↔ 形态**

| 用户 | 主要形态 | 场景 |
|---|---|---|
| 中小学 / 大学 师生 | 作业 · 测评 · 考试 | 老师布置、AI 初评、复核、学情导出 |
| 成人英语 / 培训机构 | 作业 · 测评(可带老师) | 机构班级化运营,同一套评阅闭环 |
| 成人自学者(无老师) | 练习 | 自由选题、提交文稿、对着文稿练习,AI 即时按标准评 + 逐句反馈,检测成果后按结果针对性训练——独立跑通自主学习闭环 |

## 3. BD 一页介绍(给学校 / 培训机构)

**痛点**:英语口语作业最难批——老师要逐个听录音,费时且标准难统一,学生拿不到细到句子的反馈。

**方案**:你好！作业把「口语作业」做成一条可规模化的评阅流水线:

1. **老师**发布多环节任务,**逐环节设定评分标准**(朗读、背诵、模仿、演讲各有各的标准)。
2. **学生**手机录音/录视频,逐环节提交。
3. **AI 照着老师为该环节设定的标准分环节自动评阅**:先感知发音/流利度,再对标判分、逐句反馈。
4. **老师复核**(而非逐个听),成绩、薄弱句、班级学情**一键导出**。
5. **学生**拿到个人分析与总结,顺着薄弱点**针对性再训练**。

**差异**:AI 照**老师的标准**评、而非通用模板;评阅按**环节**而非笼统一个分。

**形态**:同一套闭环覆盖**练习 / 作业 / 测评 / 考试**(考试态带正式测试防作弊)。

**部署 / 运营**:手机优先 PWA(装到手机像原生 App、竖屏优先);**多租户按校/班隔离**;三语界面(中/英/西);
AI 评阅带**用量与费用看板 + 每日上限**,批量评阅成本可控。

**适合**:中小学与大学英语教学、英语培训机构;也面向**希望提升英语表达能力的成人自学者**(练习态自助)。
